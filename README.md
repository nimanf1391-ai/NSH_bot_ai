# NSH.bot AI — نسخهٔ اولیهٔ سرور

این پروژه فایل اصلی NSH.bot را نگه می‌دارد و یک مسیر امن سرور برای پاسخ هوش مصنوعی اضافه می‌کند.

## اجرا

1. Node.js نسخهٔ 20 یا جدیدتر نصب باشد.
2. در پوشهٔ پروژه اجرا کنید: `npm install`
3. متغیرهای محیطی را در پنل میزبان تنظیم کنید.
4. اجرا: `npm start`
5. بررسی سلامت: مسیر `/health`

## متغیرهای محیطی

- `OPENAI_API_KEY`: کلید API؛ فقط در Environment سرور، نه در HTML یا GitHub.
- `OPENAI_MODEL`: مدل مورد استفاده (پیش‌فرض `gpt-4.1-mini`).
- `TAVILY_API_KEY`: اختیاری؛ برای جست‌وجوی وب. بدون آن، جست‌وجوی زنده انجام نمی‌شود.
- `MAX_REQUESTS_PER_MINUTE`: محدودیت سادهٔ درخواست برای هر IP.

## استقرار روی Render

نوع سرویس: **Web Service**؛ مخزن GitHub را انتخاب کنید. Build Command: `npm install` و Start Command: `npm start`.

پس از ساخت سرویس، کلیدها را فقط در بخش Environment وارد کنید. هیچ‌وقت فایل `.env` یا کلیدها را در مخزن عمومی/خصوصی GitHub بارگذاری نکنید.

## نکتهٔ هزینه و امنیت

پلن میزبانی رایگان به معنی رایگان بودن API هوش مصنوعی یا سرویس جست‌وجو نیست. قبل از افزودن کلید و فعال‌کردن پرداخت، تعرفه و محدودیت مصرف را با کمک والد/سرپرست بررسی کنید. محدودیت درخواست این پروژه به‌تنهایی سقف مالی تضمین‌شده نیست.

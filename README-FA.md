# NSH.bot — بسته Supabase بدون Cloudflare

این بسته سایت آموزشی را حفظ می‌کند و ورود شماره‌محور، نشست اختصاصی و پنل مالک را به Supabase متصل می‌کند.

## فایل‌ها
- `public/index.html`: سایت اصلی با رابط حساب و پنل مالک
- `supabase/functions/login-code/index.ts`: تابع Edge هماهنگ با سایت
- `schema-supabase.sql`: جداول اختصاصی نشست و همگام‌سازی

## Secrets لازم
`SUPABASE_URL`، `SUPABASE_SERVICE_ROLE_KEY`، `OWNER_PHONE` و `ADMIN_SECRET` (فقط برای صدور کد بازیابی مالک از تست داشبورد Supabase؛ هرگز در سایت قرار نگیرد).
شماره مالک باید با قالب بین‌المللی مانند `+989...` باشد. هیچ کلید محرمانه‌ای در HTML قرار نگیرد.

## نصب
1. SQL فایل `schema-supabase.sql` را در SQL Editor اجرا کنید (اگر قبلاً اجرا شده، ساختار را دوباره بررسی کنید).
2. کد `supabase/functions/login-code/index.ts` را در Edge Function با نام `login-code` جایگزین و Deploy کنید.
3. در تنظیمات تابع، Verify JWT را خاموش کنید؛ تابع نشست اختصاصی Bearer را خودش اعتبارسنجی می‌کند.
4. فقط محتویات `public` را به ریشه GitHub Pages منتشر کنید؛ `index.html` باید در ریشه باشد.

## امنیت و محدودیت‌ها
- عملیات مدیریت فقط با نشست معتبر کاربر دارای role=`owner` انجام می‌شود. تنها استثنا، صدور کد بازیابی برای خود شماره مالک با `ADMIN_SECRET` از بخش Test داشبورد Supabase است؛ این Secret هرگز در مرورگر سایت استفاده نمی‌شود.
- کد ورود ۶ رقمی، یک‌بارمصرف و ۱۲ ساعته است و باید دستی برای کاربر ارسال شود؛ پیامک خودکار وجود ندارد.
- حساب‌های این سیستم اختصاصی‌اند و Supabase Auth استاندارد نیستند.
- پیش از انتشار عمومی، rate limiting برای درخواست کد، آزمون بازیابی نشست و آزمون همگام‌سازی چنددستگاهی اضافه/بررسی شود.
